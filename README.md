# LiveRecorder Studio

抖音 / 快手 / 小红书直播录制工具。桌面窗口（内嵌 WebView2，无浏览器标签页），系统 ffmpeg 负责拉流。

## 启动

双击 `LiveRecorderStudio.exe`，直接弹出独立应用窗口，不会打开浏览器标签页，也没有黑色终端窗口。

- **隐藏 / 还原**：默认 `Alt+F1` 隐藏、`Alt+F2` 还原，可在「设置 → 快捷键」里改成任意组合；被其它软件占用会自动换备用键并在保存时提示
- **导入框快捷键**：默认 `Alt+1` 打开导入框（可自定义），窗口隐藏时也可弹出
- **关闭窗口**：三选一 —— 取消 / 缩到托盘（后台继续录制）/ 退出程序（先收尾正在录制的文件）
- 已内置测试房间（抖音 + 快手 + 小红书），点右上角「启动监测」即可

## 界面

- **搜索框**（批量导入左侧）：就地过滤列表，匹配主播名、备注、链接，不联网、不改数据
- **批量导入**：一行一个地址，支持
  - 抖音 `https://live.douyin.com/数字`
  - 快手 `https://live.kuaishou.com/u/快手号`（也认 `/profile/...`、`/fw/live/...`）
  - 小红书 `https://www.xiaohongshu.com/livestream/房间号`（带不带 `xsec_token` 都行）
  - `.m3u8` / `.flv` 直链、`demo://名字` 离线演示
  - 兼容旧格式：`超清,https://...`、`https://...,主播: 备注`
- **列表列**：状态 · 平台（图标）· 主播名 · 画质 · 已录制时长 · 操作
  - **平台图标就是活动指示灯**：录制中红色快闪、直播中青色慢闪、异常标红、未开播灰显（不再在主播名前面点）
  - 操作全部为图标，悬停出提示：文件夹 · 详情 · 立即录制/停止录制 · 删除（二次确认）
  - 悬停主播名：在播房间显示「N 在线 · 点击查看详情」，未开播仅显示「点击查看详情」
  - **排序**：录制中 → 直播中 → 检测中 → 异常 → 未开播（久未开播的沉底，方便清理）
- **右侧状态 / 运行日志**：顶栏侧栏按钮可整体收起，表格吃满宽度；点侧栏外部空白处自动收起
- **状态图标 = 预览小窗开关**：点行首平台/状态图标（闪烁那颗）弹出**浏览器小窗**看画面（置顶、可拉伸、尽量带声），再点一下收起；开启时图标带高亮圈。小窗优先浏览器画中画（PiP），不支持时退回无边框播放窗
- **详情抽屉**：显示名称 / 备注 / 平台 / 房间号 / 直播标题 / 直播链接（可显示、复制）/ 录制格式 / 画质 / 代理 / 本次录制时长 / 已录大小 / 最近录像 / 最近检查 / 监控状态与开关；底部「弹窗播放预览」与状态图标同一开关
- **设置**：检查间隔、并发数、错峰抖动、**分段录制时长**、保存格式、**默认录制画质**、**保存位置（任意路径或内置目录浏览器逐级选择）**、**隐藏/还原快捷键（点框直接按键录入）**、**手动停止后暂停监测（分钟）**、**代理地址 + 跟随系统代理**、Cookie、自动转 MP4、清空直播间列表

## 行为说明

| 场景 | 表现 |
| --- | --- |
| 新加房间 | **插队优先检查、优先开录**，不会被上千个旧房间排在后面 |
| 导入 / 导出 | 快捷键 `Alt+1`（可自定义）或右上角「+」打开导入框；支持批量粘贴、右上角粘贴按钮、底部导出列表/取消/导入 |
| 主播在播 | 自动开始录制，状态「录制中」，实时显示已录制时长 |
| 录制中改名 | 保存后**自动停止并重启录制**（新文件名立即生效），未开播的直接保存 |
| 停止录制 | 自动把 ts 无损转封装为 mp4（`-c copy`，几秒完成），成功后删除原 ts；可在设置里保留 |
| 手动停止录制 | 可设「暂停监测」冷却时间（默认 0 = 不限制），冷却期内不会被自动重新录制 |
| 主播下播 | 连续两次确认后收尾保存，状态回「未开播」 |
| 录制中断 | 记录 ffmpeg 退出码与原因，15/30/60/120 秒逐级退避后重新取流续录 |
| 文件 2 分钟不增长 | 判定流僵死，重启录制进程 |
| 网络超时 | 自动重试 3 次（1.2s / 2.4s 退避），不误报为风控 |
| 平台限流（快手「请求过快」/ 抖音 444 或验证页） | 识别为**限流**而不是下播：整平台静默 120s 起（逐次翻倍，上限 600s），期间列表显示「限流等待」；录制中的房间不受影响 |
| 抖音返回「验证码中间页」 | 判为 **IP 风控**（不是这个房间出错）：静默 10 分钟起、最长 30 分钟，并提示换代理节点比干等更快恢复 |
| 抖音探测 | 优先走轻量接口 `webcast/room/web/enter`（约 1 KB JSON，自带主播名与各档流地址），失败才退回直播间页面解析；同一 IP 上页面解析约 40 次就会被风控，接口可用次数高得多 |
| 房间很多 | 同平台请求自动排队（抖音 0.35s/次起步），命中限流就降速（最高 4s/次），正常后缓慢恢复；状态栏会显示「已降速 / 抖音静默 N 分」 |
| 小红书返回空房间 | 判为 NO_DATA（不是下播），退避后重试；小红书需要 App UA 才下发房间数据，已内置 |
| 主播名带 emoji | 自动清洗，如「懒懒ᰔᩚএ᭄」→「懒懒」 |

录像默认保存在 `downloads/平台/主播名/主播名_时间戳.mp4`：**先按平台分目录（抖音 / 快手 / 小红书 / 直链 / 演示），再按主播分文件夹**。保存位置可在设置里改到任意盘。

旧版本留下的 `downloads/主播名/` 平铺目录，会在该房间下次录制或点「文件夹」时**自动搬到 `平台/主播名/` 下**（同名文件自动改名，不覆盖）。

分段录制填 N（分钟）后，每满 N 分钟自动切一个新文件，断流最多只丢当前这一段。

## 常见问题

**一直「未开播」，但主播确实在播**
先在浏览器打开那个直播间确认状态。页面有缓存，刚开播可能要等一个周期（默认 180 秒）才刷新。也可以点该行详情里的「立即检测」强制刷新。

**快手全是「RATE_LIMIT · 请求过快」**
同一 IP 短时间高频访问会触发限流。软件已按平台级熔断退避，等一两分钟会自愈；不要为了「快」把检查间隔调到 30 秒以内。

**抖音全是「BLOCKED · 验证码中间页」**
这是**出口 IP** 被风控（常见于机房 IP、代理节点、或单 IP 高频请求），不是房间本身出错。实测单 IP 连续请求几十次页面就会被标记。处理顺序：① 在「设置 → 代理」里换一个出口（路由器 OpenClash 用户可填 `http://账号:密码@路由器IP:7893`）；② 调大检查间隔并减少同平台房间数；③ 填抖音 Cookie。软件会静默 10~30 分钟自动恢复，不必重启。

**录制报 403**
抖音 CDN 对同一 IP 反复拉流会限流。已内置递增退避，等一会儿会自己恢复。房间多时保持默认「并发 4」。

**录制反复中断**
在「设置」里填入浏览器登录后的抖音 Cookie，能显著降低风控概率。获取方式：浏览器登录抖音 → F12 → Network → 任意请求 → 复制 Request Headers 里的 Cookie 整行。

**提示找不到 ffmpeg**
确认命令行执行 `ffmpeg -version` 有输出，没有就装一个并加入 PATH。

**Alt+F1 没反应**
可能被别的软件占用。到「设置 → 快捷键」把隐藏/还原改成别的组合（点进输入框直接按键即可），被占用时保存后会提示实际生效的组合键。右下角状态栏也会一直显示当前键。

**导入框快捷键**
默认 `Alt+1`，可在导入框顶部输入框点击后按新组合键更改。修改后旧键自动失效，新键立即生效。窗口隐藏时也可弹出，关闭后自动隐藏回去。

**小红书一直 NO_DATA**
小红书对未登录请求有频率限制，且偶尔 HTTPS 握手超时（已内置 3 次重试）。持续失败时在「设置」里填入浏览器登录后的 Cookie（`web_session` 等），成功率会明显提升。

**重复双击会开两份吗**
不会。启动时先探测本机是否已有实例，有的话只再开一个窗口指向它，不会重复录制。多实例只在显式指定 `--port` 时出现。

## 目录结构

```
LiveRecorderStudio.exe   主程序（无控制台窗口）
_internal/               运行时（Python、WebView2 绑定、静态页面）
rooms.json               房间列表（可手动编辑）
config.json              设置（界面里改会自动写回）
downloads/               录像（默认位置，按主播分文件夹）
preview/                 详情里「抓取画面」生成的临时预览
logs/                    运行与 ffmpeg 日志（排查用）
.window/                 仅在 WebView2 不可用、退回浏览器应用模式时生成的临时配置
```

## 从源码运行

```bash
python selftest.py        # 离线自检（含转 MP4），不联网
python app.py             # 启动桌面窗口；--no-window 强制退回浏览器，--no-browser 不弹界面
python build.py           # 重新打包 exe（--windowed + WebView2，无控制台）
```
